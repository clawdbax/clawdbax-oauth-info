# ClawdBax OAuth information

This public site explains what ClawdBax does, which Google permissions it requests, and how to revoke access or submit a deletion request.

Serve this directory as the root of a static site. The intended GitHub Pages project URL is <https://clawdbax.github.io/clawdbax-oauth-info/>. The homepage, privacy page, and stylesheet use relative links so they work under that project path. The empty `.nojekyll` file tells GitHub Pages to serve the files without Jekyll processing. The site requires no build step.
